# E-commerce Site
An E-commerce site built using Node.js, Express, React, Tailwind CSS and MongoDB

## Status
- Backend: Completed!
- Frontend: In Progress

## Tech Stack
- Frontend: React, TailwindCSS, lucide-react
- Backend: Node.js, Express
- Database: MongoDB
- Security: JSON Web Token (JWT), bcrypt

## Features
- Admin Panel: Admin panel accessible to edit the product catalog and user roles
- Payment Gateway Integration: E-Sewa Integration completed, Khalti Integration pending
- Order Processing: Order Processing done in various phases and status
- Product Catalog: Detailed prodcut catalog with images
- API Security: Rate limit to api via express-rate-limit and role based access to APIs

## Installation
1. Clone the repo
2. Install Dependencies
- Backend: cd backend && npm install
- Frontend: cd frontend && npm install
3. Set up the .env in backend (DB URL, SECRET, PORT)
4. Run the app
- Backend: npm start
- Frontend: npm run dev
